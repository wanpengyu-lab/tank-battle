# 坦克大战 · Tank Battle

一个用纯 HTML + CSS + JavaScript 编写的经典坦克大战小游戏，单个文件即可运行，**无需任何依赖或构建步骤**。

## ✨ 玩法与特性

- 🎮 经典俯视角坦克对战：移动、瞄准、开火
- 🧱 两种地形：**砖墙**（可被炮弹击毁）、**钢墙**（不可摧毁）
- 🦅 守护己方基地，基地被毁则游戏失败
- 🤖 敌方坦克 AI：随机巡逻、锁定玩家开火
- 💥 粒子爆炸特效 + Web Audio 合成音效（无外部音频资源）
- 🏆 计分系统、生命值、多关卡（关卡递增、敌人数量递增）
- ⏸️ 暂停 / 重新开始 / 关卡推进
- 📱 响应式布局，适配窄屏

## 🎮 操作说明

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` 或方向键 | 移动坦克 |
| `空格` 或 `J` | 开火 |
| `P` | 暂停 / 继续 |
| `回车` | 开始游戏 / 进入下一关 |

## 🚀 如何运行

直接双击 `index.html` 在浏览器中打开即可。或者启动一个本地静态服务器：

```bash
# 任选其一
npx serve .
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 📁 项目结构

```
tank-battle/
├── index.html   # 游戏全部逻辑（HTML + CSS + JS 单文件）

```

## 🛠️ 技术要点

- 基于 HTML5 `<canvas>` 渲染，使用 `requestAnimationFrame` 固定步长游戏循环
- 纯原生 JavaScript，无第三方库
- 音效通过 Web Audio API 实时合成
